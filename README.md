# 🎃 Nightmare Therapy - 3D Horror Confrontation Game

An immersive, browser-based 3D Halloween exposure therapy confrontation game built with Three.js.

## 🕹️ Controls
- **Movement**: `W`, `A`, `S`, `D` or Arrow Keys (Virtual D-Pad on touch/mobile)
- **Look**: Click and drag mouse / swipe
- **Interact / Open Doors**: `E` or click on-screen INTERACT button
- **Sprint**: Hold `Shift`
- **Audio**: Click anywhere to unlock spatial 3D audio synthesizer

## 🌟 Features
- **Photorealistic PBR Materials**: Poly Haven CC0 textures with normal & roughness maps
- **Post-Processing**: Unreal Bloom, 35mm film grain, vignette, chromatic aberration
- **Stock Horror Cinema**: Classic public domain cinema looping on theater screens & morgue CRT monitors
- **Monsters & Entities**: Screaming banshee, machete stalker, possessed doll, animated spiders, 3D animated GLTF stalker
- **Safe Haven**: Find the peaceful fireplace sanctuary to overcome the nightmares
